Using Everpost

Hosting an event

You can use Everpost for free to create and share holiday invitations. Check the date, time zone and venue before sending your guest link. Only include details you have permission to share.

Guest replies

Use the RSVP and wish forms for the event you received. Keep messages respectful and avoid sending unsolicited invitations or posting someone else’s contact details without permission.

Support

Keep a copy of essential event details. Contact Everpost if a link is being misused or if you need help with an invitation.
